# b8k-video

Видео для планшета Lenovo YOGA Tablet 10 (B8000-H) с оболочкой
[lenovo-b8000h-linux](https://github.com/trudenboy/lenovo-b8000h-linux):
крупные карточки, поиск, подписки на каналы, история. Видео открывается на
весь экран в проигрывателе оболочки `b8k-vplay` (libmpv, кадры масштабирует
видеокарта), на другом компьютере — в `mpv`.

- **Подписки** — новые видео каналов, на которые вы подписаны, вместе.
- **Каналы** — сами каналы: добавить по ссылке или `@имени`, открыть, убрать.
- **История** — что вы смотрели.
- Касание карточки — смотреть; долгое нажатие — подписаться на канал или
  отписаться.

Источники — модули в `sources/`: у каждого `search`, `channel_videos`,
`find_channel`, `watch_url` (описание — в `sources/__init__.py`). Сейчас
YouTube (поиск через yt-dlp, лента канала — его открытый Atom-фид);
VK Видео, Vimeo и другие добавляются так же, файлом в `sources/`.

Нужны Python 3 с PyGObject (GTK 3), yt-dlp с JavaScript-движком (QuickJS) и
`b8k-vplay` или `mpv`. Установка: `sh install.sh [ROOT]`.

Подписки — `~/.config/b8k/video.json`, история —
`~/.local/share/b8k-video/history.json`, картинки — `~/.cache/b8k-video/`.
